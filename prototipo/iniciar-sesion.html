Historias de usuario
HU-01
Requisitos funcionales
RF-01 y RF-02 (con la restricción R-01)
Descripción
Único acceso a la zona autenticada. Presenta los campos de correo y contraseña, un aviso de simulación y un solo control principal, que es un enlace de navegación hacia el área autenticada. Incluye el ejemplo visual del error de credenciales.
Usabilidad y accesibilidad
Etiquetas asociadas con for e id; atributos autocomplete para correo y contraseña; el error va junto al campo con aria-invalid y aria-describedby, nunca con alert(); un único control principal de 48 px de alto, precedido de un aviso que lo identifica como simulación; foco visible de 3 px y una sola columna a 360 px.

Maqueta de baja fidelidad de la evidencia GA6-220501096 (AA3-EV02). Datos ficticios con fines demostrativos.

No hay autenticación funcional, backend, base de datos ni almacenamiento persistente.
